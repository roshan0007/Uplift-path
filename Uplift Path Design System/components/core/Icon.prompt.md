Wrapper around Material Symbols Rounded (weight 500), the icon set the exported site loads from jsDelivr. Intentional addition — the source has no Icon component, only raw `<img src=".../rounded/<name>.svg">` tags and `relume-icons` imports.

```jsx
<Icon name="handshake" size={48} />
<Icon name="chevron_right" color="var(--color-white)" />
```
